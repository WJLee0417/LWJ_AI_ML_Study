- 집단 간 차이는 데이터 분포와 표본 수의 영향을 받으며, 이 표만으로 차별 여부나 인과관계를 판단할 수 없습니다.

- 성별과 연령은 공정성 점검용으로만 집계하며, 자동 승인·거절의 근거로 사용하면 안 됩니다.
