# 대출 연체 위험 예측 서비스

신청자 정보를 이용해 연체 위험을 추정하고, 승인·추가 심사·거절의 자동 결정이 아닌 심사 보조 의견을 제공한다.

## 안전 원칙

- 결과는 실제 대출 승인·거절을 자동으로 결정하지 않는다.
- 민감 특성·표본 편향·과거 신용 데이터의 한계를 문서화한다.
- Test 데이터는 최종 평가에만 사용한다.
- 원본 데이터와 학습 모델은 Git에 커밋하지 않는다.

## 진행 순서

데이터 정제 → 피처 엔지니어링 → 불균형 모델 비교 → 임계값 정책 → FastAPI 예측 API → 테스트 순서로 구현한다.

## 공정성 점검

- 최종 Test 세트에서 성별 코드와 연령대별 실제 연체율, 예측 양성률, Recall, FPR을 비교한다.
- 이 분석은 배포 전 편향 모니터링이며, 차별 여부 또는 인과관계를 확정하는 평가는 아니다.
- 성별·연령은 집단별 결과 차이를 확인하는 감사 용도이며, 자동 승인·거절 근거로 사용하지 않는다.
- 결과는 results/fairness-by-group.csv와 results/fairness-report.md에서 재현한다.

### 현재 Test 점검 결과

- 정책 임계값 0.30에서 남성 코드 집단의 예측 양성률은 0.624, 여성 코드 집단은 0.565였다. FPR도 각각 0.546, 0.494로 차이가 관찰됐다.
- 60세 이상 집단은 표본이 82명으로 작고 Recall이 0.762로 다른 연령대보다 낮았다. 이 결과만으로 편향을 결론 내리지 않고, 더 큰 최신 표본에서 지속 모니터링해야 한다.
