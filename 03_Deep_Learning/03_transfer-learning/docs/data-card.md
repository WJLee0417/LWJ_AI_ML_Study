# 폐기물 이미지 데이터 카드

이 문서는 실제 데이터셋을 선택·수집한 뒤 빈칸을 채워 커밋한다. 원본 이미지와 민감한 위치 정보는 저장소에 올리지 않는다.

## 출처와 권리

| 항목 | 기록 내용 |
| --- | --- |
| 데이터셋 이름·버전 | 미기입 |
| 출처 URL | 미기입 |
| 라이선스·상업적 사용 조건 | 미기입 |
| 수집·다운로드 일자 | 미기입 |
| 책임자 | 미기입 |

## 범위와 구성

| 클래스 | 원본 이미지 수 | 고유 그룹 수 | train / validation / test | 비고 |
| --- | ---: | ---: | --- | --- |
| plastic | 미기입 | 미기입 | 미기입 |  |
| glass | 미기입 | 미기입 | 미기입 |  |

`group_id`는 같은 물체, 연속 촬영, 같은 영상 프레임처럼 동시에 분할되면 안 되는 이미지 묶음을 뜻한다. 그룹은 하나의 클래스에만 속해야 한다.

## 제외와 품질 기준

- 너무 흐리거나 대상 물체를 판별할 수 없는 이미지
- 라벨과 실제 재질이 불일치하거나 여러 재질이 동등하게 섞인 이미지
- 개인정보, 얼굴, 차량 번호판, 위치를 식별할 수 있는 정보가 있는 이미지
- 사실상 같은 이미지의 복제본. 연속 촬영본은 제외하지 않더라도 같은 `group_id`로 묶는다.

## 알려진 한계와 의도하지 않은 사용

- 데이터셋의 조명·배경·촬영 거리와 다른 환경에서는 성능이 낮아질 수 있다.
- 모델은 분리배출 조언용 보조 도구이며, 유해 폐기물·법적 분류의 최종 판정에 사용하지 않는다.
- Grad-CAM은 모델의 주목 영역을 보여 줄 뿐, 판단 근거의 인과성을 증명하지 않는다.
